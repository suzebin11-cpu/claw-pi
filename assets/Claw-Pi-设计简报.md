# Claw-Pi 视觉设计简报

> 一句话目标：为 **Claw-Pi**（U 盘版 AI 智能体桌面客户端）设计一组 Apple 极简主义风格的产品海报与渲染图，用于官网首屏 / 电商主图 / 发布物料。

---

## 一、产品速览（30 秒看懂）

- **产品**：Claw-Pi 智能体桌面客户端 · U 盘版
- **形态**：一支 U 盘 → 插入电脑 → 双击安装 → AI Agent 直接进入微信 / 飞书 / Slack / Discord
- **一句话**：插上 U 盘，你的 AI 团队就上线了
- **核心卖点**：
  1. 即插即用（U 盘 + 图形化安装，零门槛）
  2. 多平台覆盖（微信 / 飞书 / Slack / Discord 开箱即用）
  3. 数据本地化（所有业务数据留在本机，不上云）
  4. 7×24 在线（连接 IM 后 Agent 全天候工作）
  5. 开源透明（MIT 协议）
- **目标人群**：一人公司、跨境电商、自媒体、独立开发者、门店老板、律师财税
- **气质关键词**：高级 · 干净 · 工业感 · 静谧 · 科技未来感

## 五、硬规则（不可打破）

1. **Logo 必须 1:1 使用 SVG 源文件**，禁止重绘、禁止简化、禁止改色（绿色渐变只能用 `#C2F84E → #8FEF26`）
2. **品牌绿是画面里唯一的彩色**（除了第③张里聊天平台的真实品牌色图标），其它一律黑/白/灰
3. **产品名一律写作 `Claw-Pi`**（首字母大写，中间是连字符 `-` 不是空格 / 下划线 / 点）
4. **U 盘的设计语言要"高级金属 + 倒角"**，不要塑料感、不要彩色外壳、不要花哨细节
5. **每张图的负空间不少于 40%**，不要堆元素
6. **中文字体只用 PingFang SC 或思源黑体**，不要用宋体 / 楷体 / 装饰字体

## 六、可以自由发挥的地方

- U 盘的具体形态（条形 / 卡片形 / 棱角 / 圆润）
- 第①张 logo 发光的强度和氛围
- 第③张光环 / 节点的具体律动（建议略带动效感）
- 第④张桌面的小道具（绿植、笔记本、钢笔等点缀）
- 排版细节、字号比例、行距

参考草图只是给大概的"氛围 + 构图 + 文案位置"，**具体执行的精度、质感、细节请按设计师专业判断**。
