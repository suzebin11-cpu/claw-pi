技术架构与安全

基于成熟技术栈构建，安全可靠

技术架构

  • OpenClaw 运行时
    成熟的 AI Agent 框架，支持多模型、多渠道
  • ARM Linux 系统
    Armbian Debian 12，稳定可靠，低功耗运行
  • 本地 Web 管理
    Nginx + Node.js，手机浏览器即可配置
  • 自动配网
    hostapd + dnsmasq，热点模式自动引导

安全与隐私

  • 数据本地存储
    对话记录、配置文件全部保存在设备本地
  • 端到端加密
    与 AI 模型通信使用 HTTPS 加密传输
  • 无云端账号
    不强制注册云账号，离线也能查看历史
  • 一键恢复出厂
    支持完全清除数据，转让或弃用无忧
