# Claw-Pi 使用文档与常见问题

本文档面向普通用户，用于安装、登录、充值、问答、处理文件、生图、图生图、微信接入和故障排查。

## 一、安装与启动

### 1. 安装 Claw-Pi

1. 下载最新版本安装包。
2. 双击 `claw-pi-setup-版本号-x64.exe`。
3. 按安装向导完成安装。
4. 安装完成后打开 Claw-Pi。

建议使用最新版本安装包。如果旧版本打开异常，可以先关闭所有 Claw-Pi 窗口，再重新打开最新版。

### 2. 首次启动

首次启动时，Claw-Pi 会初始化本地运行环境。正常情况下会进入主界面。

如果一直停留在启动页，请等待 1 到 3 分钟。如果仍未恢复，可以点击导出诊断包并发送给客服。

## 二、登录、余额与充值

### 1. 登录账号

打开软件后，按页面提示登录账号。登录成功后即可使用龙虾大脑、龙虾工作台和微信端能力。

### 2. 查看余额

进入左侧“投喂”页面，可以查看当前余额。

如果余额暂时无法显示：

1. 点击“刷新余额”。
2. 检查电脑网络是否正常。
3. 重新登录账号。
4. 仍无法显示时，导出诊断包发给客服。

### 3. 在线充值

1. 进入“投喂”页面。
2. 选择充值金额。
3. 点击支付宝支付。
4. 用支付宝扫码完成付款。
5. 支付成功后余额会自动刷新。

如果支付后余额未刷新，请点击“刷新余额”，或关闭软件后重新打开。

## 三、普通问答

### 1. 使用龙虾大脑

在聊天框输入问题并发送即可。例如：

- 帮我总结一下这段文字
- 帮我写一个通知
- 帮我检查这段代码
- 帮我生成一个活动海报文案

### 2. 使用龙虾工作台

龙虾工作台适合需要电脑执行权的任务。例如：

- 查找桌面上的文件并总结
- 读取 PDF 或表格
- 修改 Excel
- 根据本地图片做图生图
- 生成图片并保存

如果只是让它总结或分析，默认不会修改文件。只有你明确要求“修改、保存、写入、生成文件”时，它才会写文件。

## 四、上传附件与处理文件

### 1. 上传附件

可以把文件拖到聊天框，或点击附件按钮上传。

上传后，附件会显示处理状态：

- 已保存：文件已进入对话。
- 已提取文本：可直接读取正文。
- 扫描版 PDF 无文本：文件可能是图片扫描件，需要 OCR 能力。
- 文件过大：需要拆分文件或改用本地路径。
- 解析失败：建议重新上传或提供文件路径。

### 2. 让 Claw-Pi 处理桌面文件

可以直接描述文件位置。例如：

```text
帮我找到 OneDrive 桌面上名字包含“秦洋”的简历，然后总结一下。
```

如果文件在 OneDrive、桌面或下载目录里，建议把位置说清楚。

### 3. 修改表格

如果你希望它写入 Excel，需要明确说明。例如：

```text
把这行数据加到这个 Excel 里并保存。
```

如果只是说“总结一下这个表格”，它会按只读方式处理。

## 五、图片生成与图生图

### 1. 文生图

直接描述你想要的画面。例如：

```text
生成一张 16:9 的成都夜景海报，霓虹灯风格，高清。
```

### 2. 图生图

先上传图片，再说明要怎么改。例如：

```text
参考这张图片，把整体风格改成蓝色科技感。
```

如果图片没有成功进入图生图输入，Claw-Pi 会提示重新上传或提供本地路径，避免提交无效请求。

### 3. 生图失败时怎么办

常见原因：

- 上游分组负载饱和，请稍后再试。
- 图片生成已提交，但结果返回失败。
- 上传图片没有进入图生图输入。
- 余额不足。
- 网络连接异常。

遇到失败时，不建议连续重复点击生成。可以先等待一会儿，或导出诊断包给客服判断是否已经提交到上游。

## 六、微信端使用

### 1. 连接微信

1. 打开微信接入页面。
2. 扫描二维码。
3. 在手机微信上确认登录。
4. 页面显示已登录后即可使用。

### 2. 微信扫码状态说明

- 等待扫码：二维码还没有被手机扫描。
- 已扫码待确认：手机已扫描，但还没有确认登录。
- 已登录：微信连接成功。
- 网络异常：本地网络或微信服务连接失败。
- 账号状态异常：微信账号或登录状态异常。
- 二维码过期：需要重新生成二维码。

如果用户反馈“扫码没反应”，请导出诊断包，客服可以根据状态判断原因。

## 七、导出诊断包

当遇到以下情况时，请导出诊断包：

- 软件打不开。
- 无法问答。
- 无法生图或图生图。
- 余额无法显示。
- 无法充值。
- 微信扫码没反应。
- 反复提示 OpenClaw 未就绪。

诊断包会包含本地运行状态和错误摘要，敏感字段会被脱敏。发送给客服后，可以更快判断问题原因。

## 八、常见 Q&A

### Q1：软件打开后一直卡在启动页怎么办？

先等待 1 到 3 分钟。如果仍未进入主界面，关闭软件重新打开。仍不行时导出诊断包给客服。

### Q2：为什么提示“OpenClaw 本地服务未就绪”？

这是本地执行服务还没启动完成，或上一次关闭后有残留进程。通常等待或重启软件可以恢复。反复出现时导出诊断包。

### Q3：为什么余额显示不出来？

常见原因是网络异常、登录状态过期或余额接口暂时不可用。请点击“刷新余额”，如果仍失败，重新登录账号。

### Q4：为什么充值后余额没有立刻变化？

支付回调可能有延迟。请等待 10 到 30 秒后点击“刷新余额”。如果仍未变化，保留支付记录并联系售后。

### Q5：为什么提示“余额不足，请及时充值”？

说明当前账号余额不足以继续调用模型或生成图片。请进入“投喂”页面充值。

### Q6：为什么有时候生图失败？

生图依赖上游图片模型。失败可能来自上游繁忙、网络断开、图片返回失败、提示词被拦截或余额不足。请根据页面提示处理。

### Q7：为什么图生图失败？

最常见原因是图片没有成功作为参考图传入。请重新上传图片，或提供本地图片路径。

### Q8：上传 PDF 后为什么读不到内容？

如果 PDF 是扫描件，本身没有可复制文本，需要 OCR 才能读取。可以换成文字版 PDF，或导出图片后再处理。

### Q9：我让它总结文件，为什么不能直接写文件？

总结和分析默认是只读任务，不会改动文件。只有明确要求“保存、写入、修改、生成文件”时才会写入。

### Q10：为什么回答有时比较慢？

文件处理、生图、图生图和需要本地执行的任务会比普通问答更慢。长任务期间请不要重复发送同一个请求，避免产生重复任务。

### Q11：微信扫码后没反应怎么办？

先确认手机微信是否点击了确认登录。如果页面仍无变化，重新生成二维码。仍失败时导出诊断包。

### Q12：用户反馈问题时，需要提供什么？

请提供：

- 当前软件版本号。
- 问题发生时间。
- 用户操作截图。
- 诊断包。
- 如果是充值问题，提供支付时间和金额。
