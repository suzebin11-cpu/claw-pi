7开始使用

按任务选择入口

简单问答用微信或网页；复杂任务、长文本、文件图片和多 agent 工作流，用龙虾工作台。

选择模型在模型广场切换 GPT、Claude、Gemini、DeepSeek 和生图模型。
上传文件把文档、图片、视频拖进工作台，让模型读取和处理。
连接微信扫码后在微信里直接提问，适合移动端快速使用。
安装绝技文档处理、数据分析、IT 运维和行业技能按需安装。
8新用户提示

遇到问题先看这三点

问答入口点不了：等待服务显示“已准备好”。
微信不回复：确认微信已扫码连接，并且模型广场有可用模型。
图片或生图失败：确认当前模型支持视觉或生图能力。
