Quick Start

2. 快速开始

安装并启动运行安装包，首次启动时等待本地服务准备。若界面提示“服务启动中”，请不要连续点击问答入口。
登录或配置模型推荐使用 Claw-Pi 账号；高级用户也可以选择自带 API Key 的方式。
进入模型广场选择聊天模型。需要图片生成时，还要确认生图模型可用。
选择使用入口日常问答可用龙虾工作台；想让微信自动回复，去龙虾窝连接微信；想看 OpenClaw 原生聊天，打开网页龙虾。

首次使用的判断标准

  • 侧边栏能正常进入“龙虾工作台”“模型广场”“绝技”等页面。
  • 模型广场里已有当前模型，或你已经配置了自己的模型服务。
  • 微信扫码后显示已连接，并且服务状态不再处于准备中。
  • 龙虾工作台输入框可点击，发送按钮可用。
如果刚启动、刚扫码、刚切换模型后第一条消息慢一点，通常是服务预热或配置同步。等状态稳定后再测试速度更准确。

3. 主要界面说明

龙虾窝

用于查看小龙虾状态、连接微信/Web 等渠道。新用户一般从这里完成“放龙虾出去”的动作。

网页龙虾

这是 OpenClaw 原生 Web 聊天入口，适合验证底层问答是否可用，也适合需要原生会话体验的用户。

龙虾工作台

面向日常使用的多会话问答界面，支持切换模型、上传文件和图片、图片预览/复制/下载、知识库、清除上下文、Token 和耗时显示。

模型广场

管理聊天模型和生图模型。当前聊天模型会同步到微信、网页龙虾和龙虾工作台；生图模型用于文生图、图生图等图片任务。

绝技

技能市场用于展示和安装技能；“我的”用于查看已安装技能；导入按钮可添加自定义 zip 技能包。

投喂

查看余额、充值入口和模型计费信息。不同模型的输入、输出和图片生成价格可能不同，以平台最终展示为准。

Models

4. 模型与生图

聊天模型

聊天模型负责文字问答、长文本分析、代码、总结、规划等任务。你在模型广场切换聊天模型后，龙虾工作台、微信和网页龙虾会使用同一套当前模型状态。

生图模型

生图模型负责文生图、图生图和图片编辑。若你在龙虾工作台上传图片并要求“换颜色”“生成同款”“改风格”，系统会优先走图片生成能力。

文件和多模态

  • 文本文件、文档内容会作为上下文发给模型，适合总结、提取、改写。
  • 图片能否被理解，取决于当前模型是否支持视觉能力。
  • 视频等大文件可能需要等待更久，建议先压缩或截取关键片段。
不要让用户误以为所有模型都能生图。生图和图生图需要当前账号/接口具备对应图片模型能力。

Skills & Knowledge

5. 绝技、知识库与上下文

绝技是什么

绝技可以理解为给小龙虾增加“专业能力”的技能包，例如文档处理、数据分析、行业技能、IT 运维、代码开发、网页搜索等。

安装技能

  1. 进入“绝技”。
  2. 切换到“技能市场”。
  3. 按分类或搜索找到技能。
  4. 点击“安装”，等待安装完成后即可使用。

导入自定义技能

点击“导入”，选择包含 SKILL.md 的 zip 文件。导入成功后会出现在“我的”中。

知识库

龙虾工作台里的知识库适合放固定资料、产品说明、客服话术、项目背景等。问答时系统会自动检索相关内容加入上下文。

上下文与速度

上下文越长，模型需要读取的信息越多，响应时间可能变长。遇到长对话变慢时，可以使用“清除上下文”保留当前聊天记录但减少后续模型读取压力。

当前策略会尽量避免把所有技能详情都塞进每次问答，只在需要时命中相关技能，从而减少对回复速度的影响。

How-to

6. 常用操作流程

连接微信

  1. 进入“龙虾窝”。
  2. 选择微信入口，点击连接。
  3. 用微信扫码登录。
  4. 等界面显示已连接、服务准备完成后，再发送测试消息。

在龙虾工作台发起问答

  1. 进入“龙虾工作台”。
  2. 选择模型，或保持模型广场同步过来的当前模型。
  3. 输入问题，按 Enter 发送；换行可用 Shift + Enter。
  4. 需要文件/图片时，点击附件按钮或直接粘贴图片。

生成或编辑图片

  1. 确认模型广场中已连接可用的生图模型。
  2. 在龙虾工作台输入清晰的图片需求。
  3. 图生图时先上传参考图片，再说明要修改什么。
  4. 生成后可点击图片放大、复制或下载。

Q&A

7. 常见问题 Q&A

Q1：扫码后显示已连接，但为什么第一条消息慢？

扫码后还可能有配置同步、会话预热、模型连接确认等步骤。建议等界面显示服务准备完成后再测试第一条消息。

Q2：为什么官网或 Cherry Studio 更快？

官网通常只走单一问答链路。Claw-Pi 多了桌面端、控制器、OpenClaw 网关、微信/Web 通道、上下文和技能检索等步骤，因此需要关注本地链路和配置同步。

Q3：龙虾工作台和模型广场的模型是否同步？

是。聊天模型切换后会同步到微信、网页龙虾和龙虾工作台。若界面还没刷新，可稍等几秒或重新进入页面。

Q4：为什么我不能生图或图生图？

需要账号或接口支持生图模型，并且当前生图模型可用。仅聊天模型无法完成图片生成。

Q5：上传图片后模型没有看懂怎么办？

确认当前聊天模型支持视觉能力；如果只是想修改图片，建议明确写“基于这张图生成/编辑”。

Q6：长文本输入后无响应怎么办？

长文本会增加上下文读取压力。建议拆分文本、先总结再追问，或清除上下文后重新发送核心内容。

Q7：绝技安装后会拖慢问答吗？

系统会尽量使用轻量索引和按需命中，避免每次问答都加载所有技能详情。安装大量技能后仍建议只启用真正需要的能力。

Q8：图片能不能下载、复制和放大？

可以。在龙虾工作台里，输入图片和模型返回图片都应支持放大查看、复制和下载。

Q9：中文路径能不能用？

当前 Windows 安装包和本地运行流程按中文路径场景处理过，建议仍避免把安装目录放在权限受限或同步冲突严重的位置。

Q10：遇到异常应该先看哪里？

先确认服务是否准备完成、模型是否可用、微信是否已连接；再检查是否有网络、账号或余额问题。
