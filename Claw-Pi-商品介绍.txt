【商品名称】
Claw-Pi 智能体桌面客户端 · U盘版

【一句话介绍】
插上 U 盘，双击安装，你的 AI Agent 直接进入微信、飞书、Slack、Discord——一个人就能拥有一支 AI 团队。

【产品简介】
Claw-Pi 是一款开源桌面客户端，让 AI 智能体（Agent）直接运行在你的日常聊天工具中。无需服务器、无需编程、无需复杂配置——插入 U 盘，双击安装，扫码连接微信，你的 AI Agent 就上线了。

所有数据保存在本机，隐私安全，完全可控。

【核心亮点】
1. 即插即用：U 盘插入电脑，双击安装，全程图形界面，零门槛上手
2. 微信直连：适配微信 OpenClaw 插件，扫码即可让 AI Agent 进入微信对话
3. 多平台覆盖：内置支持微信、飞书、Slack、Discord，开箱即用
4. 顶级 AI 模型：内置 Gemini 等主流模型，也支持自带 API Key
5. 7×24 在线：连接 IM 后，Agent 全天候在线，手机随时对话
6. 数据本地化：所有数据保存在你的电脑上，不经过第三方服务器
7. 开源透明：MIT 开源协议，代码可审计，安全放心

【系统要求】
- macOS 12 及以上（Apple Silicon / Intel 均支持）
- Windows 10 及以上
- 磁盘空间：约 500 MB

【U盘规格】
- 容量：内含 Claw-Pi 安装包 + 快速入门指南
- 兼容：USB-A / USB-C（视具体型号）

【安装步骤】
1. 将 U 盘插入电脑
2. 打开 U 盘，双击安装程序
3. 按照图形引导完成安装
4. 启动 Claw-Pi，登录账号或填入自己的 API Key
5. 点击连接微信 / 飞书 / Slack，扫码即可开始使用

【常见问题】
Q: Claw-Pi 免费吗？
A: 客户端完全免费，开源（MIT 协议）。内置多款顶级 AI 模型可直接使用，也可选择自带 API Key。

Q: 需要联网吗？
A: 需要联网以连接 AI 模型服务和 IM 平台，但你的业务数据不会上传到第三方服务器。

Q: 支持哪些 IM 平台？
A: 内置支持微信、飞书、Slack、Discord，开箱即用。

Q: 数据安全吗？
A: 所有数据保存在本机，源码开源可审计。我们不托管你的业务数据。

Q: 可以用自己的 AI 模型 API Key 吗？
A: 完全可以。填入 API Key 即可使用，无需注册账号或登录。
